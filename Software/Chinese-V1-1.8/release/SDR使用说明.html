Hapticpad Windows SDR 通用版 1.0

这是“设备输入 → 本机控制台 → CAT → 电台/SDR软件”的通用方案。适配当前 V1-CN-1.2，无需重刷固件。控制台只调整频率和接收模式，没有 PTT/发射按钮。

先安装与测试

1. 在 Mac 中文工具箱中点击「追加 SDR 通用配置」，再「写入 SD 并应用」。也可以导入随包的 config.xml：它保留原有16套 Mac/Win 手感配置和已开启的电机总开关，新增第17套「SDR通用」。网页支持在你自己的当前配置上追加，更适合以后继续修改。

2. 把整个文件夹解压到 Windows。安装 Python 3.10 或更新版本，保留默认的 Tcl/Tk 和 Python Launcher 组件（官方安装包通常默认包含），双击 启动SDR控制台.cmd。不需要 pip 包。

3. 先选择「演示」，点击「连接」和「开始接管」。界面按钮和模拟旋钮可验证逻辑，演示不连接真实电台。

4. 设备用上方小键切换到「SDR通用」。先测试实体六键，旋钮一格应改变当前步进对应的频率。顺时针方向相反时勾选「反转调频方向」，不改电机线序。

5. 停止接管，选择下述真实接口，读到实际频率后再开始接管。

六键和旋钮

位置中文标签动作设备输出
上排左 1步进减减小调频步进Ctrl+Alt+F1
上排中 2步进加增大调频步进Ctrl+Alt+F2
上排右 3模式前上一种模式Ctrl+Alt+F3
下排左 4模式后下一种模式Ctrl+Alt+F4
下排中 5频段前上一个预设频段Ctrl+Alt+F5
下排右 6频段后下一个预设频段Ctrl+Alt+F6
旋钮调频每格 ± 当前步进Alt+鼠标滚轮

步进：1 / 10 / 50 / 100 / 500 Hz，1 / 5 / 10 / 100 kHz，初始100 Hz。

模式：LSB → USB → CW → CWR → AM → FM → 数字USB → 数字LSB。电台不支持某模式时会显示错误并停止，重新连接后可继续；不是所有驱动都支持全部模式。

频段键跳到预设接收频率：1.9、3.7、7.1、10.12、14.2、18.1、21.2、24.94、28.4、50.1、145、435 MHz。它只设置频率，不自动改模式、天线或硬件波段。超出设备范围时驱动可能拒绝，控制台会停止。可在 radio.py 的 BANDS 中修改预设。

只有连接成功并按「开始接管」后，程序才注册六键快捷键、拦截 Alt+滚轮。普通鼠标滚轮继续正常使用；任何鼠标的 Alt+滚轮也会被识别，不能区分具体 HID 设备。按「停止接管」释放输入，再切回设备的 Win 常用配置。退出软件、掉线、重连后均不自动开始接管。已交给 CAT 的单条命令不能撤销，积压输入不会在重连后重放。

路线 A：OmniRig（适合已有 OmniRig 环境）

安装 OmniRig 1.x，在其设置程序中配置 Rig1 或 Rig2。先确认它显示 ONLINE，且其他 CAT 测试客户端能读/改频率。再在本控制台选择对应 Rig1/2。

驱动必须匹配所接的“软件CAT端口”或电台本身。若 COM 注册失败，修复官方 OmniRig 安装并检查 Python/COM 位数兼容。控制台通过 PowerShell 的官方 COM 接口调用 OmniRig，不需要修改 PowerShell 执行策略。

程序按驱动的可读/可写能力修改当前接收 VFO；不强制切成单工，不交换 A/B，不改 RIT、分频或 PTT。频率按基准 VFO 显示，RIT 偏移不计入数字；OmniRig 回报正在发射时拒绝修改。设置完成后必须收到频率/模式回读确认，未确认则停止，避免继续按错误基准累加。

路线 B：Hamlib rigctld（通用 TCP CAT）

安装有目标型号驱动的 Hamlib。它的 rigctld 是电台驱动服务，这个 Python 控制台是它的客户端。先在命令行运行：

rigctl -l | findstr /I "X6200 Kenwood TS-480 TS-2000"

按实际驱动列表选择编号。示例命令中的占位内容必须替换为实际值：

rigctld -m 型号编号 -r COM端口 -s 波特率 -T 127.0.0.1 -t 4532

在控制台选择 Hamlib，地址 127.0.0.1，端口 4532，点击连接。两端必须使用兼容的默认协议；本控制台用 Hamlib ERP（+f / +m / +F / +M）进行读写。若其他软件已经提供 rigctld 兼容服务，直接连接它，不要再起同端口服务。

虚拟串口须成对连接，不能让两个独立程序同时打开同一个物理 COM 口。由一个 CAT 服务占用电台串口，再让客户端连接服务。

几款软件怎么选接口

设备/软件先在电台软件里完成控制台连接
SunSDR2 / ExpertSDR2、3按具体版本启用其 CAT 接口。虚拟串口成对建立，CAT模拟型号、波特率按软件设置一致；不是选择设备名字就能连上对应CAT驱动的 OmniRig，或对应模拟协议的 rigctld
奥德赛 / Thetis、PowerSDR在软件 CAT 设置中启用虚拟串口，并确认当前版本的模拟型号。电脑已使用 OmniRig 时可复用同一 OmniRig Rig 槽OmniRig 或匹配模拟协议的 rigctld
协谷 X6200安装该机 USB/CAT 驱动，按设备手册识别正确COM口、波特率和CAT参数。先在Hamlib列表里确认有 X6200优先 X6200 的 rigctld 驱动；也可用已验证的 X6200 OmniRig 驱动

截至2026-10-27检查的 Hamlib master 源码 rigs/icom/xiegu.c 已有独立 X6200 驱动；你安装的发行版不一定含此驱动。列表没有 X6200 时更新到包含它的版本，不能假设 X6100 驱动通用。本版未实现 ExpertSDR 原生 TCI、厂商专用USB协议或自动识别电台；这些软件都要先打通上述CAT接口。

排查与修改

- 能演示、不能连电台：先检查 CAT 服务、驱动、COM占用和地址；与 Pico 电机接线无关。

- 频率可以读，不能改：驱动只读、VFO未知、软件远程控制未开启或设备不支持该操作。先用对应 CAT 工具确认能改频。

- 旋钮有记录但不调频：设备须在 SDR 配置，控制台须已接管；确认输出含 Alt，且当前桌面与程序权限级别一致。无需默认管理员启动。

- 提示快捷键冲突：关闭占用 Ctrl+Alt+F1～F6 的程序，再重新接管。

- 手感沿用“中刻度”（力度50、阻尼12、1.5V、每圈40格），可以在现有网页更换轻刻度/平滑阻尼；普通Win、Mac配置不会因此改动。

- 按键绑定可以在网页编辑，但如改了 Ctrl+Alt+F1～F6，须同步改 windows_input.py；中文标签不影响实际动作。

- python -m unittest discover -s tests -v 可运行本地协议与控制逻辑测试。
