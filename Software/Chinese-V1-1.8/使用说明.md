# Hapticpad 中文工具箱组合键版 1.8

此文件夹是可复制的本地工具箱，不依赖原电脑的文件路径，没有自动更新。
内置固件 V1-CN-1.8，保留中文屏幕、宠物气泡、彩色拖尾和3分钟待机。
本次新增组合键和独立选择/设置界面。已完成本地编译及逻辑验证，未刷设备、未写SD，实机操作待你回家验收。

## 换电脑使用

1. 把整个压缩包复制到另一台电脑，完整解压，不能只复制HTML。
2. 安装 Python 3.9 或更高版本（https://www.python.org/downloads/）。无需安装pip依赖。
3. Mac 双击 `启动工具箱.command`；Windows 双击 `启动工具箱_Windows.cmd`。
4. 在Chrome或Edge打开 http://127.0.0.1:8768/ 。使用期间保留启动窗口。
   如果端口被旧版占用，先关闭旧版，或在此文件夹终端执行：
   Mac：`python3 server.py --port 8767 --open`
   Windows：`py -3 server.py --port 8767 --open`

127.0.0.1表示当前电脑。换电脑后需在新电脑运行工具箱；旧电脑的地址不会成为公共网站。
可将本地地址收藏，下次先启动程序，再打开收藏。

## 各电脑支持情况

| 平台 | 编辑、导入、导出 | 写入SD | 刷固件 |
|---|---|---|---|
| Apple Silicon Mac | 支持 | 原生自动流程或目录选择 | 原生备份、刷写、读回校验 |
| Windows / Intel Mac + Chrome或Edge | 支持 | 浏览器串口切模式、选择SD目录写入 | 浏览器串口切刷机模式、选择RPI-RP2目录复制 |
| Safari或不支持浏览器设备接口的平台 | 支持 | 导出XML、手动复制 | 下载UF2、手动进入刷机模式并复制 |

Windows浏览器硬件流程尚未在Windows实机验证；本地接口与文件写入保护已测试。
浏览器需提供 Web Serial 和 showDirectoryPicker；浏览器策略可能限制串口或可移动盘选择。
原生Mac自动连接按当前设备序列号E46468C09732292D匹配；换Pico请使用浏览器选择设备流程。

## 配置按键、手感、灯效和屏幕

- 先读取设备SD中的config.xml，再编辑。内置19套配置是出厂备份，不自动代表设备最新内容。
- 点击“录入快捷键”，在电脑键盘按组合键，再确认中文名称。
- 新增设备多键组合触发，例如同时按1+2、1+2+3；在网页“设备组合键”勾选物理键并录入对应电脑快捷键。
- 网页草稿只存在各电脑浏览器中。必须写入SD后，设备才会使用新配置。
- SD上的配置随设备保留，无需在每台电脑重新设置。Mac与Windows的快捷键预设需自行切换。

Apple Silicon Mac可直接使用“读取SD配置”“写入SD并应用”。
其他电脑按跨电脑区域的顺序操作：
1. 浏览器连接并检测，选择Hapticpad设备。
2. 点击切换SD卡U盘模式，等待系统挂载。
3. 选择SD目录并读取；修改后选择同一SD根目录写入。
4. 工具要求目录内已有有效config.xml；先创建时间戳备份，再覆盖，并读回比较。
5. 在操作系统安全弹出SD卡，然后点击“安全弹出SD后恢复使用”。

若浏览器拒绝目录访问：点击“导出config.xml”，在资源管理器或Finder中先备份SD旧config.xml，
再复制导出的config.xml到SD根目录（确保文件名不是config (1).xml），安全弹出后重启设备。
台词库下载后解压，将四个词库文件放到SD根目录；无需重新格式化SD。

## 刷固件

只改配置无需刷固件。支持内置固件和自己选择的RP2040 UF2，接线及16MB Flash布局需匹配设备。

- Apple Silicon Mac：选择固件后用原生“刷入中文V1固件”，有现有固件备份与Flash读回校验。
- 浏览器方式：先选择固件，切换到刷机盘，等出现RPI-RP2，再选择此盘目录复制。
  此方式校验UF2结构和RP2040 family ID，但不提供Flash读回校验。
  复制完成后需等待设备重启，再检测版本并检查显示、按键和旋钮。
  如果复制时刷机盘断开，网页会提示无法确认；不要把提示当成成功。
- 软件进入模式需要设备固件支持HP命令；旧固件无响应时，需手动BOOTSEL进入刷机模式。

设备出现U盘但按键暂停，通常是SD配置模式，安全弹出并恢复使用即可。
不要在两个网页或串口软件中同时操作同一设备。

## 1.8默认导航

| 操作 | 功能 |
|---|---|
| 短按7 / 短按8 | 下一套 / 上一套配置（到边界停止） |
| 长按7（约0.65秒） | 配置选择；旋钮浏览，短8确认，短7取消 |
| 长按8（约0.65秒） | 进入设置 |
| 设置中1～6 | 配置、力度、阻尼、灯效、亮度、旋钮模式 |
| 设置中旋钮 | 浏览项目；选中项目后调整数值 |
| 设置中短7 / 短8 | 返回或取消当前字段 / 选择或确认字段 |
| 设置中长7 / 长8 | 放弃所有未保存调整并退出 / 保存到SD并退出 |

设置是草稿调整；长8保存后才应用。保存时校验临时文件并保留config.menu.bak。
选择其他配置后短8确认会载入该配置的设置，再继续调整。

## 组合键容量与配置

默认“保留7/8导航”：1～6可用，共63种非空组合，7/8保持上表操作。
若选“7/8自定义”：8个单键及多键组合可配置，长按7+8约0.8秒进入设置；这个组合的长按保留给菜单。
若选“全部自定义”：8键所有255种组合均可配置，不再保留硬件菜单入口，修改需使用网页。

按1、2、3、4、5、6、7、8个键的组合数分别为8、28、56、70、56、28、8、1；单键到三键共92种。
每套最多8个单键加247个多键组合；配置总文件不超过64KB，最多32套，不能假定每套都能塞满255种。
物理组合按同时按下识别，默认100ms收集窗口，可调50～250ms。必须全部松开才能触发下一次；未配置的组合不回退成单键。
每项仍输出最多3个电脑按键槽，例如Ctrl+Shift+C；不是任意长度文本或宏脚本。执行中的快捷键未结束时不排队。
已有旧配置可直接读取，缺省不启用新组合；为保持你的现有配置，本包不会自动添加组合或覆盖SD。

## 回家刷入顺序

1. 下载整包，完整解压，启动工具箱，使用Chrome/Edge打开本地页面。
2. 先读取SD配置并导出备份，或手工复制整个SD卡到电脑。台词库不用重写。
3. 切回正常模式，选择内置1.8固件刷入；也可将release/Hapticpad_V1_CN.uf2复制到RP2040刷机盘。
4. 先用原SD配置检查显示、静止电机、旋钮、7/8长短按，再在网页添加组合并写入SD。
5. 验收：1+2只触发所配动作、不额外触发1或2；长7选择、长8设置；设置长7放弃，重新进入后长8保存并重启核对。
6. 检查彩色拖尾、宠物和3分钟待机。新版本未在你的设备上刷入验收，不将主机测试视为实机通过。

## 源码与验证

固件源码位于firmware/MacroPad；构建目标为Waveshare RP2040 Plus、16MB Flash、TinyUSB。
使用Arduino-Pico 6.3.1与SimpleFOC、U8g2、SdFat、Adafruit NeoPixel依赖；GPIO保持原V1兼容接线。
Python模型测试：`python3 -m unittest discover -s tests -p 'test_*.py'`。
完整主机测试需clang++、Node和ArduinoCore-API，设置ARDUINO_API指向其api目录后运行 `python3 tests/verify_local.py`。
启动网页后运行 `python3 tests/verify_portable.py` 验证接口、导出及UF2哈希，不操作硬件。
