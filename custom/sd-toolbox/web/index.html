六键布局

7、8小键与组合键

最多8键同时按

正常使用：7、8短按切换配置，长按8进入配置选择、旋钮浏览、7短按确认、8短按取消；长按7进入设置。设备设置：1选择配置，2调力度，3调阻尼，4选灯效，5调亮度，6选旋钮模式。旋钮调整；8短按返回，7短按确认；长按8放弃并退出，长按7保存到SD并退出。选中其他配置并确认时会重载该配置的参数。

新增设备组合键

这里选择设备上的按键，再录入要发送给电脑的快捷键。1＋2与2＋1视为同一组合。必须在等待时间内同时按住，未配置的组合不触发单键。

请选择至少两个键

每套最多8个单键＋247个多键组合＝255种；单键至三键共92种。SD配置总文件最多8MB、256套；每套最多64KB。固件只保留当前方案及名称索引。大于64KB或超过32套的总配置需先刷1.10.0；旧配置可直接沿用。

屏幕看板

配套1.10.0固件：六键仅显示中文名称，不显示组合键提示；配置名自动缩写，例如 Mac中刻度 → M中刻。配置名只在按7/8进入菜单时显示，平时中间为宠物自由活动区，保留N/F反馈开关标识。宠物会停下来冒出说话气泡：按编号随机抽取SD词库，避免相邻重复，长句自动换行，各行同时显示，不再逐段刷新。这里修改后需导出配置并写入SD卡才会生效。

查看动画效果：上方小狗，下方小人

下载编号台词库：小狗576句 + 小人576句 · 编辑TSV后重新生成索引，把四个词库文件放到SD根目录。编号是对应文件内的行号，直接定位读取，不把整份词库装入内存。

自动待机：设备连续3分钟未按键或转动旋钮，屏幕和灯环熄灭、电机停止输出；再次按键或转动可唤醒。宠物动画和电脑轮询不会延长待机计时，U盘配置模式不自动待机。

电机手感

每套配置独立保存

内置1.10.0固件支持以下参数；编辑后需写入SD卡才能生效。

更多手感设置：刻度密度、转速、助转时间

助转先要求停稳250ms，再由转动触发；每次推动结束后需再次停稳。截止转速用于停止助推，不会限制你用手快速旋转。力度为相对设置，未标定实际扭矩。

无极续转

电机补偿 · 物理旋转

停稳约120ms后拨动旋钮：连续读取有效编码器读数，丢弃第1次；三次取第2、3次均值，两次取第2次，只有一次不驱动。没有额外的采样间隔或峰值等待，再乘下面的续转倍率。目标转速随时间下降，不会因电机自己的转动反复续期。按住、明显减速、反转或进入菜单会取消补偿。

倍率100%使用选出的速度，130%以该速度的1.3倍作为初始目标，再逐渐减速；受转速与输出上限约束，实际转速需实测。遇阻会撤力，倍率不会反复叠加。电压越高，补偿能力越强，运行上限取这里与“驱动输出上限”的较小值。0V关闭补偿。制动百分比越高、确认时间越短，越容易取消。只有编码器，无法精确识别手指触摸。实体不转时不额外生成页面惯性滚动。

旋钮与灯光

沿用现有接线

固定跟随：主色是亮点。彩色拖尾：每到下一颗灯随机换色，前一颗在2秒内淡回背景；停手约2秒后整圈统一，背景设为黑色即全灭。20颗灯每格约18°，零位随上电初始化，方向与滚动方向独立。1.10.0保留此前确认稳定的同步PIO灯环发送方式。

第一次使用 / 设备操作说明
  1. 连接设备并点“检测设备”，再点“刷入中文 V1 固件”。旧固件若不支持 USB 软件复位，网页会说明失败原因，需要先让设备进入 BOOTSEL。
  2. 刷完后可点“读取 SD 配置”导入现有配置，或直接编辑内置 Mac / Win 预设。
  3. 选择配置，修改六键、旋钮方向和灯光，点“写入 SD 并应用”。自动切换 U盘可能需要约一分钟。
  4. 上方两个小键：短7上一套，短8下一套；长8选择配置、旋钮浏览、短7确认、短8取消。长7进入设置，长7保存退出、长8放弃退出。
  5. 刻度模式适合普通滚动。“回中模式”本来就会把旋钮拉回中心，只有需要这种操作时再选。
  6. 重启后默认使用第一套配置。在设备上切换后会记住所选配置。开机按住第 5 个大键也可进入 U盘模式，按第 1 个大键退出。

启动方法与各平台功能请阅读随包《使用说明》。需先运行本地服务，直接双击HTML不能完整使用。Windows浏览器USB流程尚未经实体Windows电脑验证。
