# Hapticpad 中文工具箱 1.10.0 · SD按需配置

配套固件 V1-CN-1.10.0-SD，适用当前 Hapticpad V1 接线的 RP2040 Plus 16MB。

## 开始使用

1. 安装 Python 3.9 或更新版本。
2. macOS 双击 `启动工具箱.command`；Windows 双击 `启动工具箱_Windows.cmd`。
3. 打开 http://127.0.0.1:8770/ 。先检测设备，再读取SD配置，避免用预设覆盖自己修改过的内容。
4. 编辑按键、组合宏、手感及灯效后，点击“写入SD并应用”。原生Mac流程会备份、回读核对并弹出SD；目录流程请按网页提示安全弹出后恢复。

Apple Silicon Mac提供原生USB桥接（仅操作工具中指定的Pico）；Windows/其他电脑可用Chrome/Edge浏览器USB与目录选择，或导出XML手工复制。内置UF2与自选UF2都可刷入。自动刷机先备份完整16MB Flash，再写入并回读校验。

## 存储方式与限制

全部方案保存在SD根目录 config.xml。上电扫描文件，仅保存名称和偏移索引；RAM常驻当前一套解析后的按键、旋钮和灯效参数。切换时读取目标段，校验成功再替换当前参数，失败保留当前方案。

最多256套、整个XML最多8MiB；单套Profile最多64KiB，全局Settings最多4KiB。总文件不再受64KiB限制。限额用于控制索引、启动扫描耗时和单套解析峰值，并非SD物理容量；每套仍可含8单键及247个多键组合。默认导航模式只启用1～6的63种非空组合，7/8保持导航。

第二核心使用独立8KiB栈，容纳SD校验及FAT调用；只为此固定预留8KiB，不随方案总量增长。菜单保存通过2KiB缓冲区复制前段、更新当前段、复制后段，写临时文件后逐字节核对，再替换。保留 config.menu.bak；其他方案的未知字段、格式和内容保持原字节。启动时主配置缺失会尝试恢复备份。这不是对任意SD硬件故障或断电时文件系统完整性的保证。

旧XML可直接沿用。超过旧总量64KiB或32套前请先刷1.10.0；不要用旧工具箱重新保存大配置或数字宏。网页支持NumberText/EnterAfterText原样往返，重新录入普通快捷键会替换该数字宏。

## 实体7/8

当前实物编号：7=GP14、8=GP13；内部存储位序保持兼容。网页显示实体编号。

- 短7上一套，短8下一套。
- 长8选择配置，旋钮浏览，短7确认、短8取消。
- 长7进入设置；短7确认、短8返回，长7保存到SD并退出、长8放弃退出。
