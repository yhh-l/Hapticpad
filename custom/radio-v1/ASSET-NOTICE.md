# OLED character artwork

The seven monochrome frames in MacroPad/feiyu_sprites.h are reductions of the
classic atlases embedded in the locally installed dsh-bigfish 0.6.0 package.
They retain the same character used in the computer companion.

Upstream notice: dsh-bigfish is an independent community companion, not an
official DeepSeek product. Original character artist/source was not identified
in the supplied references. Six derived built-in sprite atlases were generated
for that project on 2026-09-17. No ownership of the original character artwork
or DeepSeek trademarks is claimed. The code MIT license does not license
underlying third-party character rights.

The OLED conversion uses local Pillow processing and introduces no new AI art.
